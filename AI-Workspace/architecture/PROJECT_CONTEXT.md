# Project Context

## Mission

The AI Workspace is the project's source of truth, serving as an evolving Knowledge Base that will accompany this project throughout its entire lifecycle. The documentation must be usable by various AI models including ChatGPT, Claude Sonnet, Claude Opus, Gemini, Local Qwen, and Cline.

## Project Overview

This project represents a Swift web framework built for iOS applications, leveraging SwiftUI and Swift Concurrency. The framework is designed to support modern iOS development with a focus on clean architecture, accessibility, and Apple Human Interface Guidelines.

## Technologies

- SwiftUI: For building user interfaces with a declarative syntax
- Swift Concurrency: For handling asynchronous operations and concurrent programming

## Target Platform

min iOS 15

## Design Principles

- Apple Human Interface Guidelines: Adherence to Apple's design standards and principles
- Soft UI: Implementation of soft, modern UI elements
- Accessibility: Ensuring the application is accessible to all users
